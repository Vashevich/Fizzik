# Архифизика

Физическая песочница в смешанной реальности для Meta Quest 3. Кубики и шарики с гравитацией падают на настоящий пол, стол, стул и диван: приложение берёт поверхности и мебель из настройки пространства Quest.

**Открыть:** https://vashevich.github.io/fizzik/ — в браузере Quest 3 нажми «Войти в смешанную реальность». На компьютере открывается превью с виртуальной комнатой.

## Управление
| Кнопка | Действие |
|---|---|
| Курок | создать фигуру в руке, отпустить с замахом — бросить |
| Grip | схватить фигуру рядом или лучом издалека |
| A | кубик ↔ шарик |
| B | гравитация вкл / выкл |
| X | показать / скрыть скан комнаты |
| Y | убрать все фигуры |
| Левый стик (нажать) | настроить пространство |
| Руки | щипок создаёт или хватает, разжать — бросить |

Чтобы фигуры вставали на мебель, отметь её в Quest: Настройки → Физическое пространство → Настройка пространства.

## Как устроено
Один файл `index.html`: three.js для графики, cannon-es для физики, WebXR `plane-detection` и `mesh-detection` для пола, стен и мебели. Реальная мебель перекрывает виртуальные фигуры и принимает от них тени.
