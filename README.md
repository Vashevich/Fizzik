# VRfizzik

Простая рисовалка в браузере: нарисованные линии и точки подчиняются физике. Версия 1 рассчитана на компьютер и мышь.

**Открыть:** https://vashevich.github.io/Fizzik/

## Что умеет
Рисуешь линию мышью, она превращается в цепочку точек. Дальше на неё действуют четыре типа сил.

| Сила | Что делает |
|---|---|
| Нагрузка | Вектор силы. По умолчанию вниз (гравитация), включена сразу. Направление: вниз, вверх, влево, вправо; сила от 0 до 2 (0 — нагрузки нет). |
| Якорь | Закрепляет точку полностью: она никуда не двигается. |
| Пружина | Слайдер от −1 до 1 для линий. 0 — длина как нарисована, 1 — вдвое длиннее, −1 — вдвое короче. Действует на выбранные линии, а если ничего не выбрано — на все. |
| Коллизия | Пол есть всегда, ниже него ничего не уходит. Дополнительно: потолок и предметы (прямоугольники). |

## Инструменты
- **Рисовать** — тянуть мышью. Конец рядом с точкой замыкает линию.
- **Якорь** — нажать на точку, чтобы закрепить или отпустить.
- **Выбрать** — выбрать линию (Shift — добавить к выбранным), затем двигать «Пружину».
- **Тянуть** — тянуть точку или предмет.
- **Стереть** — убрать точку, линию или предмет.

Шаг назад и вперёд: кнопки или Ctrl+Z / Ctrl+Y. Шагом считается действие (нарисовал, закрепил, изменил значение), а не кадр расчёта.

## Выгрузка
- **JSON** — всё состояние, чтобы продолжить работу (кнопка «Открыть JSON…»).
- **OBJ** — линии и точки в текущем положении (после провисания). 1 единица = 100 px, ось Y вверх, Z = 0. Проверить импорт в Rhino предстоит отдельно.
- **PNG** — картинка для показа.

## Как устроено
Один файл `index.html`, без библиотек. Расчёт по методу Верле: точки, связи с заданной длиной, несколько проходов за кадр. Прежняя версия (кубики и шарики для Meta Quest) убрана: это был предварительный тест.
